# Layout iteration: screenshots

So we can iterate on layout **without you testing blind**, use this workflow:

1. **Run the app** and open the screen you want to change (e.g. Session History → tap a session, or first results after upload).
2. **Take a screenshot** (device or simulator: Cmd+S in Simulator).
3. **Save it here** with a clear name:
   - `session-detail.png` – session detail (video + Overview/Issues/Notes)
   - `first-results.png` – analysis sheet right after upload/record
4. **Tell me** you’ve added/updated the screenshot (e.g. “screenshot is in Previews/session-detail.png”).

I can **read the image file** and suggest concrete layout changes (spacing, hierarchy, what to remove or simplify). After you apply changes, repeat with a new screenshot to iterate.
